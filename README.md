# DigiYatra Kids – Jetty prototype

A coded prototype of a kids' (5–16) DigiYatra redesign. Jetty, a friendly private jet, guides a returning young flyer through onboarding, the airport journey (entry, check-in, security, boarding) and trip completion.

Single static page: `index.html` (no build step, no dependencies; fonts load from Google Fonts).

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. On vercel.com choose Add New > Project and import the repo.
3. Framework Preset: Other. Leave Build Command and Output Directory empty. Click Deploy.

Note: the grown-up PIN and uploaded photos are demo-only and kept in memory; any 4 digits work.
